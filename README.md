# 🌍 CarbonTracer - Carbon Footprint Awareness Platform

## Overview

CarbonTracer is an interactive web application developed for the Hack2Skill Carbon Footprint Awareness Challenge.

The platform helps users:

* Measure their annual carbon footprint
* Understand major emission sources
* Receive personalized sustainability recommendations
* Track progress over time
* Learn how lifestyle choices affect the environment
  
AI TOOL USED ANTIGRAVITY 

The goal is to encourage climate-conscious decisions through awareness, visualization, and actionable insights.

---

## Problem Statement

Climate change is one of the most pressing global challenges. Many individuals are unaware of how daily activities contribute to carbon emissions.

CarbonTracer provides a simple and engaging way to:

* Calculate carbon emissions
* Visualize environmental impact
* Identify high-emission activities
* Promote sustainable living practices

---

## Features

### Carbon Footprint Calculator

Calculates emissions from:

* Home Energy Usage
* Transportation
* Flights
* Diet
* Waste Generation

### Personalized Recommendations

Provides tailored suggestions to reduce emissions based on user inputs.

### Progress Tracker

Allows users to monitor improvements and compare historical results.

### Interactive Dashboard

Visualizes emissions using:

* Pie Charts
* Bar Charts
* KPI Cards
* Carbon Score Metrics

### Sustainability Education

Includes Carbon 101 resources and environmental awareness content.

### Frontend

* Streamlit

* CSS

### Backend

* Python

### Data Processing

* NumPy

### Visualization

* Plotly

### Testing
